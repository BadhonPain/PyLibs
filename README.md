## 🐼 Pandas — Topics Covered

| Topic | What I Learned |
|-------|----------------|
| **Series** | Creating series from lists & dicts, `loc`, `iloc`, custom indexing, conditional access |
| **DataFrame** | Building DataFrames, adding columns & rows, `concat` |
| **Importing Data** | Loading CSV (Titanic dataset), JSON files, `head()`, `tail()`, `info()`, `describe()` |
| **Selection** | Column selection, row slicing, multi-column selection |
| **Filtering** | Conditional filtering, boolean indexing |
| **Aggregate Functions** | `mean()`, `median()`, `groupby()`, `sum()`, `count()` |
| **Data Cleaning** | Handling missing values (`isnull()`, `fillna()`, `dropna()`), removing duplicates |
